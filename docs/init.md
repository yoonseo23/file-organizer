# 기획안: 바탕화면·다운로드 폴더 자동 분류 파이프라인

> 레포 이름(가안): `auto-file-organizer`

## 1. 한 줄 소개
바탕화면과 다운로드 폴더에 새 파일이 생기면 규칙에 따라 알맞은 폴더로 옮겨주는 로컬 자동화 도구.

## 2. 문제 정의
- 다운로드 폴더에 과제 PDF, 이미지, 설치 파일, 압축 파일이 뒤섞여 쌓인다.
- 나중에 파일을 찾을 때 이름도 위치도 기억나지 않는다.
- 정리를 "나중에" 미루다 결국 안 한다.

## 3. 동작 흐름
```
새 파일 감지 → 분류 규칙 적용 → (선택) 이름 정리 → 이동 → 로그 기록
```

## 4. 분류 규칙 (단계적으로 확장)
| 단계 | 기준 | 예 |
|---|---|---|
| 1 | 확장자 | `.pdf` → 문서, `.png` → 이미지, `.dmg/.exe` → 설치파일 |
| 2 | 파일명 키워드 | `보안시스템` 포함 → `학교/보안시스템운영/` |
| 3 | 날짜 | `2026-11/` 월별 하위 폴더 |
| 4 | (선택) LLM 분류 | 애매한 파일만 내용·이름 보고 카테고리 제안 |

규칙은 코드가 아니라 `rules.yaml` 같은 설정 파일로 분리 → 코딩 없이 수정 가능하게.

## 5. 안전 원칙 (가장 중요)
- **삭제하지 않는다.** 이동만 한다.
- **dry-run 모드** 먼저: "이렇게 옮길 예정" 목록만 출력
- 같은 이름 파일 있으면 덮어쓰지 않고 `_1` 붙이기
- 다운로드 중인 파일(`.crdownload`, `.part`) 무시
- 모든 이동을 로그로 남기고 **되돌리기(undo)** 명령 제공

## 6. 기술 스택 (안)
- Python 3
- `watchdog` (폴더 변화 감지) 또는 주기 실행 방식
- 설정: YAML
- 상시 실행: macOS `launchd` / Windows 작업 스케줄러
- (선택) LLM 분류: Anthropic API — 파일 내용 전송 범위 신중히 결정

## 7. 마일스톤
| 단계 | 내용 |
|---|---|
| M1 | 확장자 기준 분류 스크립트 + dry-run |
| M2 | 규칙 파일(YAML) 분리, 로그·undo |
| M3 | 실시간 감시 + 부팅 시 자동 실행 |
| M4 | 키워드·날짜 규칙 |
| M5 | (선택) LLM 분류, 간단한 설정 UI |

## 8. 열린 질문
- 사용 OS: macOS / Windows?
- 바탕화면은 "임시 작업 공간"으로 두고 일정 기간 지난 것만 옮길까?
- 개인 파일 내용을 외부 API로 보내는 것을 허용할지? (프라이버시)
